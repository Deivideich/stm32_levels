# Item cards

The roadmap ([../roadmap_v4.md](../roadmap_v4.md)) is an **index**: one line per item with the
acceptance test ("Done when"). A card is the exercise itself:

- why the item matters in firmware,
- the vocabulary you need,
- a starting experiment (with starter code under `NNN/`),
- questions to answer in `notes/NNN.md`,
- progressive hints, hidden until you open them,
- an optional "go further".

Cards never contain the solution. If a card exists, read it before starting the item.
`tools/new_item.sh NNN` copies the starter files into your level folder.

Cards available: 001 to 005. More are added level by level.
