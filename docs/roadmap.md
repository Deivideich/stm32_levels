# STM32 Bare-Metal Mastery

**Version:** 4.2

A bottom-up curriculum for one person, one desk and two boards (three if you count the second G431KB). **266 items · 6 phases · 5 gated capstones (+1 optional) · ≈710 h of net work.**

Every item is a small, checkable exercise ("Done when: ...") and every level ends with a reusable **block** (a ring buffer, a state machine, a UART driver, a bootloader...). The idea is the same as a good FPGA roadmap: you learn by building the small pieces yourself, in an order where each one stands on the previous.

## About this guide

- **Who it is for:** someone who can read C and wants to become genuinely good at embedded firmware, not just able to run CubeMX. It does not assume prior embedded experience.
- **What you end up able to do:** write your own startup, linker script and build; drive timers, ADC, UART/DMA, SPI, I2C and CAN with timeouts and failure paths; ship a field-updatable node with an atomic, authenticated bootloader; run a fixed-point control loop under an RTOS with an analysed task set; and keep all of it honest with host tests, static analysis and CI.
- **What it deliberately does not cover:** see Appendix D.
- **Primary board:** NUCLEO-G431KB (Cortex-M4F). Everything except the optional Phase 6 runs on it (two boards from Phase 3).
- **Numbering is generated by a script** from the item list, so counts and ranges cannot drift.

## 0. How it works

### 0.1 Rules

1. One item at a time. Inside a phase, in order. Inside a level, the order is free. The roadmap line is the **index and the acceptance test**; when a card exists for the item (`docs/items/NNN.md`) read it first: it explains why the item matters, gives a starting experiment and progressive hints.
2. Every item leaves an artifact in `evidence/NNN/` (capture, log, map excerpt, diff, test result) and one line in `notes/NNN.md` about what surprised you.
3. An item is **PASS** (its "Done when" is met and the artifact proves it) or **GAP** (something is missing; write what in one line and come back later). A GAP is a to-do, not a judgement.
4. **◈** marks an item where you must also **provoke the failure and observe it**. A ◈ without an artifact of the failure is a GAP even if the function works.
5. **Block** (the last item of a level): leave a reusable module in the level folder, with host tests and its contract documented in the header. It moves to `lib/` only when a later level needs it.
6. Build from the command line. No IDE project that you cannot rebuild from scratch.
7. Stuck for more than 90 minutes: write down the state, stop, and come back tomorrow.
8. If you already know an item cold, pass it in one sitting with its artifact and move on. Do not re-study.
9. Read Appendix A before each phase and check Appendix B (instrumentation) before starting it.

### 0.2 Sizes

| Size | Effort | Hours used in the estimate |
|---|---|---|
| **S** | one sitting, ≤ 1 h | 0.75 |
| **M** | half a day, 2–4 h | 3 |
| **L** | 1–4 days; includes every block | 12 |

If the topic is new to you, multiply by 1.5. An L item that stretches past a week should be split, not dragged along.

### 0.3 Gates

A phase ends when all three hold:

- the capstone is PASS;
- three items of that phase, picked at random, are redone **without notes and on hardware**, and all three pass (if not, the gate waits a week);
- no GAP remains in the phase.

Reading the next phase is always allowed.

**Items that are impossible with your hardware:** write "N/A: reason" in `notes/` and do the substitute given in the item itself, or the closest one. At most 3 per phase.

### 0.4 Weekly review

Once a week, 10 minutes: redo one random item from an earlier phase. If it has rusted, this will find it.

### 0.5 If you fall behind

Drop to one item per day. Never skip a level.

### 0.6 Repository layout

    levels/NN_name/      one folder per level
      Makefile           include ../../mk/host.mk   (levels 1-2, PC)
                         include ../../mk/target.mk (levels 3+, board)
      NNN_slug.c         one item = one file (+ NNN_*.h if needed)

    tools/               doctor.sh, new_item.sh, openocd.cfg, .gdbinit
    docs/                roadmap, prerequisites, pin map, budgets
    board/               (from level 3) g431kb/ and host/ stubs
    lib/                 (later) promoted blocks: ringbuf, fsm, crc...
    vendor/              CMSIS headers, never edited

## Phase 1 — Language and build
Foundations. Without them, everything else is copying from CubeMX with extra steps.

### Level 1 — C that bites in embedded
**Prerequisite:** none. **Verified with:** host `gcc`, `nm`, `objdump`, sanitizers.

- **001** `M` Discover how long a variable lives: predict the output of a counter experiment and of a pointer to a dead local variable, run it with and without the sanitizer, and explain what you saw. — *Done when:* your predictions were written before running, you can say where each variable lives and for how long, and you can explain why the buggy program looked correct.
- **002** `M` Discover who can see what: read a module's symbols with `nm`, make it export only functions, and prove it from the object file. — *Done when:* `nm` on the object shows no exported data symbols (no uppercase `B`/`D`), the only uppercase `T` symbols are your public functions, and the program still prints the same result through an accessor.
- **003** `M` Describe a hardware register twice, as a bitfield and as masks and shifts, and compare them. — *Done when:* your masks come from the datasheet, an exhaustive test over every field combination passes at `-O0` and `-O2`, and you can explain why bitfields are risky for registers.
- **004** `M` Make a `FIELD_SET` that replaces one field of a register without touching its neighbours, guided by a failing test suite. — *Done when:* every test passes at `-O0`, `-O2` and with sanitizers, and your notes explain each bug of the naive first attempt.
- **005** `M` Predict the type and value of arithmetic on small integer types, and correct your guesses against the compiler until you can state the rule yourself. — *Done when:* `make 005` exits 0 with your own guesses, and you can explain why multiplying two 16-bit values is undefined behaviour.
- **006** `M` Remove mixed signed/unsigned arithmetic and implicit narrowing (`uint8_t x; x += 200;`). — *Done when:* the build is clean with `-Wsign-compare -Wsign-conversion -Wconversion` and every narrowing is an explicit cast or a wider intermediate.
- **007** `S` ◈ Trigger a signed overflow (`INT32_MAX + 1`) and compare `-O0` with `-O2`. — *Done when:* the results diverge, you capture it and explain the cause in one line.
- **008** `S` Use `volatile` only where the compiler cannot know better: ISR flags, registers, memory-mapped state. — *Done when:* you delete two decorative `volatile`s without breaking anything, and the `-O2` disassembly shows a busy-wait that disappeared without `volatile`.
- **009** `S` Measure a struct's padding, reorder it, and pin its layout with `_Static_assert` (size, offsets, alignment, enum range; at least five assumptions). — *Done when:* a change of layout or type breaks the build with a clear message.
- **010** `S` Parse a byte buffer with `memcpy`, with no pointer casts. — *Done when:* the parser runs clean under `-fsanitize=undefined,address` on the host.
- **011** `S` Write explicit serialisation of `uint16_t`/`uint32_t` in little and big endian. — *Done when:* a host test checks both orders and does not depend on the host's endianness.
- **012** `S` Place `const` correctly: `const char *`, `char * const`, `const char * const`. — *Done when:* you fix three existing signatures and the intent is unambiguous.
- **013** `M` Dispatch through a table of function pointers instead of a `switch`. — *Done when:* a table of five handlers dispatches correctly and `nm`/`objdump` places it in `.rodata`.
- **014** `S` Propagate errors as values (`enum status_t`) through three levels of calls. — *Done when:* no error is dropped without a return or a log (`-Wunused-result` watches this).
- **015** `M` Replace `malloc` with a static pool of fixed-size blocks. — *Done when:* 1000 alloc/free cycles without fragmentation, exhaustion is reported cleanly and there is no `malloc` in the link.

### Level 2 — Host tests and CI from day one
**Prerequisite:** Level 1. **Verified with:** `make check`, the pipeline.

- **016** `S` Pick a minimal test runner (Unity or 30 lines of your own around `assert`). — *Done when:* `make check` runs the Level 1 tests and exits non-zero if one fails.
- **017** `S` Build the tests with `-Wall -Wextra -Wconversion -Werror` and sanitizers. — *Done when:* a deliberate sanitizer failure breaks the test.
- **018** `M` Create a CI workflow that runs `make check` on every push. — *Done when:* a push with a broken test goes red and is blocked.
- **019** `S` ◈ Add `cppcheck` (or `clang-tidy`) to CI so findings break the build. — *Done when:* a finding introduced on purpose breaks CI.
- **020** `S` Write a regression test **before** the fix for a real bug from Level 1. — *Done when:* the test fails before the fix and passes after, in separate commits.

### Level 3 — Toolchain, startup and linker
**Prerequisite:** Level 2. **Verified with:** the `.map`, `size`, `sha256sum`, a clean tree.

- **021** `S` Pin the `arm-none-eabi-gcc` version and build with `-mcpu=cortex-m4 -mthumb -mfloat-abi=hard -mfpu=fpv4-sp-d16`. — *Done when:* `readelf -A` confirms the architecture and the version is recorded in the README and in CI.
- **022** `M` Read ST's reference linker script and annotate every region (FLASH, SRAM1, SRAM2, CCM). — *Done when:* every region has its size and contents annotated and checked against RM0440.
- **023** `M` Write your own linker script for the G431KB (128 KB flash, 32 KB RAM, CCM separate). — *Done when:* the build links and `size` matches the map.
- **024** `S` Place the vector table in flash at the right address. — *Done when:* `.isr_vector` appears at `0x08000000` in the map and reset works.
- **025** `M` Write your own startup: reset handler, copy `.data`, zero `.bss`, call `main`. — *Done when:* a global initialised to 7 reads 7 in `main` and an uninitialised one reads 0.
- **026** `M` ◈ Enable the FPU in the reset handler (`CPACR`) before any code that uses `float`. — *Done when:* a floating-point operation runs; removing the enable causes a UsageFault you capture.
- **027** `S` ◈ Enable `-ffunction-sections -fdata-sections --gc-sections`. — *Done when:* deleting a call shrinks the map and no orphan sections remain.
- **028** `S` Read a `.map`: find a symbol, its section and its size. — *Done when:* you locate three symbols of your choice and state their region.
- **029** `S` Compare the size of two builds and attribute the difference. — *Done when:* `size` and the map explain the difference line by line.
- **030** `S` ◈ Build with `-O2 -g3 -Wall -Wextra -Wconversion -Wsign-conversion -Werror`. — *Done when:* the build is clean and a deliberate narrowing breaks it.
- **031** `M` Make the build reproducible: fixed `SOURCE_DATE_EPOCH`, sorted inputs, no timestamps in strings. — *Done when:* two clean builds are identical under `sha256sum`.
- **032** `M` Reduce the build to one command from a clean tree. — *Done when:* `git clean -xdf` followed by `make <item>` produces a working binary.
- **033** `S` Embed a semantic version and a build ID in a dedicated section of the binary. — *Done when:* `strings`/`objdump` show them, the version changes with a tag and the ID with any source edit. (Printing them at boot waits for Level 6.)
- **034** `M` Choose an assertion strategy: trap with file and line in debug, compiled out in release, never `assert()` on a recoverable condition. — *Done when:* a forced assertion halts in the debugger with its location and the release build contains no assertion code (`objdump`).
- **035** `S` ◈ Set a binary size budget. — *Done when:* exceeding it breaks the build.
- **036** `M` Flash and debug from the command line (OpenOCD + GDB). — *Done when:* `make <item> flash` and `make <item> debug` work without an IDE.
- **037** `M` Isolate board differences under `board/`: the shared application code compiles unchanged for the G431KB and for a host "board" made of stubs. — *Done when:* it compiles for both and the host version runs inside `make check`.

### Gate 1 — Capstone A

**Dual-blink from an empty tree.** Two independent blink modules built from an empty directory: your own linker script, startup and Makefile, reproducible and under a size budget. One blinks at 1 Hz and the other at 3 Hz with 30 % duty. Neither uses a hardware timer, only SysTick. Use the board LED and an external LED on a second pin (the Nucleo-32 has a single user LED).
**Done when:** both blink, the build is reproducible, `size` is under budget, and the timing logic has at least one host test that passes in CI.
**Forbidden:** CubeMX output, IDE project files, `HAL_Delay`, a shared clock divider between the modules.

## Phase 2 — Pins, time, interrupts and first serial

### Level 4 — Clocks and GPIO
**Prerequisite:** Gate 1. **Verified with:** logic analyser, datasheet, register dump.

- **038** `M` Trace the clock tree from HSI/HSE to a peripheral bus. — *Done when:* the tree is drawn with every prescaler and mux on the path labelled.
- **039** `M` Configure the PLL at 170 MHz (with the right flash latency and power mode per RM0440) and confirm with MCO divided by a prescaler your analyser can measure. — *Done when:* the analyser measures the expected frequency on MCO.
- **040** `S` ◈ Raise the frequency without adjusting the flash latency. — *Done when:* you observe the failure (hard fault or erratic behaviour), capture it and fix it.
- **041** `S` Enable the GPIO clock in `RCC` and then remove it. — *Done when:* the pin responds with the clock and stops responding without it.
- **042** `M` Set mode, speed, pull and output type explicitly for every pin you use. — *Done when:* a register dump of your init shows no unreviewed default fields.
- **043** `S` Drive an output through BSRR/BRR and explain why it is atomic. — *Done when:* two pins toggle with one instruction each and the disassembly has no read-modify-write.
- **044** `S` Read a pin through IDR by polling and measure the latency with `DWT->CYCCNT`. — *Done when:* you report the number of cycles.
- **045** `S` Configure a pin as an alternate function using the AF number from the datasheet table. — *Done when:* the AF field matches the table and the signal appears.
- **046** `S` Configure a pin as analog (disconnecting the digital buffer). — *Done when:* you measure current or noise with and without the buffer and explain that this is not isolation.
- **047** `M` Drive an open-drain pin with an external pull-up. — *Done when:* the line rises when released and you document the rise time (oscilloscope; without one, compute the RC and check the level on the analyser).
- **048** `S` Compare two slew rates on the same net. — *Done when:* the two captures are compared.
- **049** `S` ◈ Respect BOOT0 and the SWD pins: never reconfigure them blindly. — *Done when:* the board is still debuggable after your init. (Check the board manual for which pin shares a boot function with your LED.)
- **050** `M` Write the pin map: pin, function, AF, direction, pull and the constraint that forced it. — *Done when:* someone could rebuild your wiring from the document alone.
- **051** `S` Drive an LED and a button behind an abstraction with no register names in `main`. — *Done when:* `main` calls `led_on()` and `button_pressed()`.

### Level 5 — Time, NVIC and EXTI
**Prerequisite:** Level 4. **Verified with:** logic analyser, cycle counter.

- **052** `S` Use SysTick as a monotonic millisecond counter. — *Done when:* it advances at 1 kHz on the analyser and `DWT` confirms it within ±1 %.
- **053** `S` ◈ Handle counter wrap in timeout comparisons. — *Done when:* a timeout survives the 2^32 wrap (host test with simulated time and on the board by forcing a start value).
- **054** `M` Write a `delay_ms` that does not block interrupts. — *Done when:* an ISR keeps firing during a 500 ms delay.
- **055** `S` Set the NVIC priority grouping and assign preemption and sub-priority on purpose. — *Done when:* you explain the choice and its consequence.
- **056** `M` Configure an EXTI line on a button with a pull-up and software debounce. — *Done when:* 50 presses produce exactly 50 events.
- **057** `S` Keep the ISR to a flag and do the work in the main loop. — *Done when:* the ISR body is under ten instructions in the disassembly.
- **058** `S` ◈ Forget to clear the EXTI pending bit and observe the continuous re-trigger. — *Done when:* you capture the behaviour and the handler fires once per edge after the fix.
- **059** `M` Measure interrupt latency from the edge to the first instruction of the ISR. — *Done when:* you report the number and the configuration that produced it.
- **060** `M` ◈ Give a real-time source the highest preemption and a background task the lowest; demonstrate an inversion and fix it by assigning priorities. — *Done when:* the inversion is reproducible before the fix and gone after it.
- **061** `S` Measure the length of a critical section in cycles. — *Done when:* the window is measured.
- **062** `M` ◈ Detect a missed deadline: a flag still set when the next event arrives. — *Done when:* an overload increments a counter visible in the debugger (the log arrives in Level 6).
- **063** `L` **Block:** `timebase` module: `now_ms()`, `deadline_after()`, `deadline_expired()`, with host tests that cover wrap. — *Done when:* the tests pass in CI and Capstone A uses the module.

### Level 6 — Minimal UART TX and logging
**Prerequisite:** Level 5. **Verified with:** logic analyser, terminal.

- **064** `M` Configure the USART connected to the ST-LINK VCP at 115200 8N1 with blocking byte-by-byte transmit. — *Done when:* you see the bytes in the terminal and the analyser decodes 115200.
- **065** `S` Compute `BRR`, measure the real baud rate and its error. — *Done when:* you report the error as a percentage and it is within what the receiver tolerates.
- **066** `M` Write a bounded `log_printf` with levels (ERR/WARN/INFO/DBG) and a timestamp from `now_ms()`. — *Done when:* the DBG level compiles to zero bytes in release and you measure the cycle cost of one line.
- **067** `S` Evaluate the cost of `%f` support in `printf` (newlib-nano). — *Done when:* you measure the flash delta and decide whether to enable it.
- **068** `S` Print version, build ID and reset cause (`RCC->CSR`) at boot. — *Done when:* you can tell a power-on start from a reset-pin start.

### Level 7 — Basic concurrency
**Prerequisite:** Level 6. **Verified with:** stress runs, analyser, host tests with threads.

- **069** `M` ◈ Show that `volatile` is not atomic: an ISR increments a `volatile uint32_t` while `main` decrements it. — *Done when:* you measure the drift and capture it.
- **070** `M` ◈ Fix the drift with a critical section (`PRIMASK`/`BASEPRI`) or C11 atomics, and explain why `volatile` failed. — *Done when:* the drift is 0 over 10^6 cycles.
- **071** `S` List the state shared between each ISR and `main`. — *Done when:* every object is listed with its writer and its reader.
- **072** `M` Implement a lock-free SPSC ring buffer with head and tail indices. — *Done when:* 10^6 transfers with no loss or corruption (host test with two threads and on the board).
- **073** `S` Make the capacity a power of 2 and wrap with a mask. — *Done when:* the disassembly has no divisions and the code is shorter.
- **074** `M` ◈ Distinguish full from empty without ambiguity. — *Done when:* a full buffer rejects cleanly, an empty one returns a sentinel and neither is read as data.
- **075** `S` Detect producer overflow without blocking the ISR. — *Done when:* an overflow counter increments and the consumer logs the loss.
- **076** `M` Use a double buffer when the producer must always finish writing. — *Done when:* the consumer never sees a torn frame.
- **077** `S` Apply a compiler or memory barrier (`__DMB`, `atomic_signal_fence`) where order matters. — *Done when:* you name the reordering that breaks without it.
- **078** `M` ◈ Starve the consumer on purpose. — *Done when:* the producer stays healthy and the overflow path is exercised.
- **079** `S` Document the concurrency contract of every shared object in its header. — *Done when:* each one declares writer, reader and guarantee.
- **080** `L` **Block:** A generic, static `ringbuf` module with host tests. — *Done when:* it passes in CI and `log` or UART can use it.

### Level 8 — State machines in C
**Prerequisite:** Level 7. **Verified with:** host tests. (This is the counterpart of the FSM level in an FPGA roadmap.)

- **081** `M` Implement an FSM with an `enum` and a `switch` that detects the button sequence "short-short-long". — *Done when:* every state and every transition has a test.
- **082** `M` Rewrite the FSM as a table (state × event → action, next state). — *Done when:* the same suite passes and you compare size and readability.
- **083** `M` Build a debounce as an FSM on top of `timebase`, with no blocking delays. — *Done when:* simulated bounces on the host and real ones on the board: 50 presses give 50 events.
- **084** `M` ◈ Handle illegal events: every undefined (state, event) pair goes to a logged error state instead of being ignored. — *Done when:* injecting an illegal event raises a counter and emits a log line.
- **085** `M` Add state timeouts with a deadline. — *Done when:* the timeout fires on the right tick, even across a wrap.
- **086** `M` Build an event queue with run-to-completion: ISRs publish and a dispatcher processes. — *Done when:* the button FSM and the timeout FSM share the dispatcher with no blocking.
- **087** `L` **Block:** Reusable `fsm`, `debounce` and `button` modules with tests. — *Done when:* they pass in CI and Capstone B uses them.

### Gate 2 — Capstone B

**Button-to-event pipeline.** A debounced button (FSM) produces timestamped events into the `ringbuf`. A consumer drains them, formats them with `log` and prints them over the Level 6 UART TX. Lost events are counted and reported. Interrupt latency is measured and stated.
**Done when:** 100 presses produce 100 events with no loss, the latency figure is in `notes/`, and the FSM and `ringbuf` have tests in CI.
**Forbidden:** busy-waiting on the button, a consumer poll longer than one tick, or dropping an event silently.

## Phase 3 — Timers, analog, buses and persistence
This is where the work stops being "make an LED blink" and becomes "move real data".

### Level 9 — Timers
**Prerequisite:** Gate 2. **Verified with:** logic analyser (oscilloscope if you have one), the second board as a pulse source.

- **088** `S` Configure a basic timer with a periodic interrupt. — *Done when:* a pin toggled in the ISR shows on the analyser the period you set in `ARR`.
- **089** `S` Compute `PSC` and `ARR` for a target frequency and state the rounding error. — *Done when:* the error is below 0.1 % or justified.
- **090** `M` Use input capture to measure a pulse width. — *Done when:* a 1 ms pulse generated by the other board measures as 1 ms ±1 tick.
- **091** `M` Generate PWM with a duty sweep from 0 to 100 %. — *Done when:* the analyser measures the duty and the 0 % and 100 % extremes have no glitch.
- **092** `M` ◈ Resolve the timer clock doubling: with an APB prescaler other than 1, the timer clock is 2×PCLK. — *Done when:* a frequency came out double what you expected for this reason, and you fix it.
- **093** `M` Read an encoder (real, or generated by the other board). — *Done when:* the count goes up and down when the direction reverses.
- **094** `M` Start a slave timer from another's update event (master/slave) and generate a delayed one-shot pulse. — *Done when:* the offset is fixed and measured.
- **095** `M` Generate complementary PWM with dead time. — *Done when:* the analyser shows the dead time between edges and its value matches the configured one.
- **096** `M` ◈ Capture at 10 kHz without losing edges for a minute. — *Done when:* you count edges sent against edges captured and they match.
- **097** `M` ◈ Use the independent watchdog (IWDG) as a deadline detector: only the healthy path refreshes it. — *Done when:* a stuck loop causes the reset and the log names the cause.
- **098** `M` Calibrate HSI against LSE (or HSE if your board has it) with a timer capture. — *Done when:* you report the deviation in ppm.

### Level 10 — ADC
**Prerequisite:** Level 9. **Verified with:** multimeter, potentiometer, the second board or a known divider.

- **099** `M` Do a single software-triggered conversion on a known resistive divider. — *Done when:* the reading matches the measured voltage and you quantify the error in LSB.
- **100** `S` Read `Vrefint` and compute the real VDDA; convert to volts using the factory calibration. — *Done when:* the converted voltage matches the multimeter within your quantified error.
- **101** `S` Run the ADC calibration before using it. — *Done when:* you measure the offset with and without calibration.
- **102** `M` ◈ Choose the sampling time from the source impedance and demonstrate the error with a sampling time that is too short on a high-impedance source. — *Done when:* the error is visible and you fix it with a longer time.
- **103** `M` Trigger the conversion from a timer and handle end-of-conversion in an ISR. — *Done when:* the sampling instants line up with the timer with no software trigger.
- **104** `M` Scan several channels with circular DMA into a buffer. (First use of DMA; Level 15 goes deeper.) — *Done when:* a known signal lands in the expected buffer position with no CPU involvement.
- **105** `M` Apply hardware or software oversampling and measure the noise of a fixed input. — *Done when:* the standard deviation drops by the expected ratio and you report the effective bits gained.
- **106** `S` Read the internal temperature sensor and convert to °C with the factory calibration. — *Done when:* the reading is reasonable against a thermometer (±3 °C).
- **107** `M` ◈ Use the analog watchdog to fire an ISR when a threshold is crossed. — *Done when:* the ISR fires on the crossing and re-arms.
- **108** `L` **Block:** An `adc_drv` module that returns millivolts, with calibration and per-channel sampling-time selection. — *Done when:* it passes a host test with a simulated ADC and Capstone C uses it.

### Level 11 — Full UART and protocols
**Prerequisite:** Levels 7 and 10. **Verified with:** logic analyser and the second board.

- **109** `M` Configure UART with DMA RX into a circular buffer, using `ringbuf` where it fits. — *Done when:* 1 kB/s for a minute with no overrun.
- **110** `M` ◈ Handle idle line, framing and overrun: force each one and report it. — *Done when:* each error shows up reported and none is ignored.

- **139** `M` Build a configuration record with CRC, version and two alternating pages. — *Done when:* cutting power mid-write, at different points and 20 times, always leaves a valid configuration.

- **141** `M` ◈ Read a half-programmed flash area to provoke an ECC error (if your family reports it; see RM0440). — *Done when:* the flag or the NMI is seen and handled.
- **142** `L` **Block:** A `cfgstore` module with host tests against a flash simulator. — *Done when:* it passes in CI, survives a simulated power cut and Capstone C uses it.

### Level 14 — Structures and memory
**Prerequisite:** Levels 11 and 12. **Verified with:** the `.map`, `size`, stack watermark.

- **143** `M` Serialise field by field instead of `memcpy` of the struct. — *Done when:* the byte order is defined and a test passes with another compiler (clang and gcc).
- **144** `S` Put read-only tables in flash. — *Done when:* the map shows `.rodata` and RAM does not grow with the table size.
- **145** `S` Use a union to alias a register only where it is safe. — *Done when:* the access compiles to a single load or store and you document when it is not safe.
- **146** `M` ◈ Create a RAM budget: stack, heap, statics and buffers. — *Done when:* everything fits with margin and every entry has an owner.
- **147** `S` Place a hot buffer in CCM and confirm it in the map; check in RM0440 whether DMA can reach CCM on your family. — *Done when:* the map shows the section and you write down the DMA restriction.
- **148** `M` ◈ Detect stack overflow with a canary and stack painting. — *Done when:* deep recursion trips the check.

### Gate 3 — Capstone C

**Sensor bridge.** An SPI sensor, an I2C sensor and one ADC channel (`Vrefint`/internal temperature, or a potentiometer), sampled by a timer and published over UART in CRC-protected frames at a fixed rate. **Done when:** you hot-unplug each sensor and the bridge does not hang, the configuration survives a reset, the parser and the NACK, timeout and CRC paths have tests in CI, and the RAM budget closes.
**Forbidden:** blocking on an absent sensor, `malloc`, or letting a dead sensor stall the other.

## Appendix A — Anti-patterns this plan wants you to unlearn

Read it before each phase.

1. **Waiting with a filler loop** (`for (i=0;i<1e6;i++)`). Use `timebase`.
2. **`HAL_Delay` in an ISR.** It blocks the time source you are waiting on.
3. **`malloc` at run time.** Use pools and static buffers.
4. **`volatile` as a substitute for atomics.** It is not one (Level 7).
5. **`printf` inside an ISR.** Record an event and print it from another context.
6. **Ignoring the return value.** `status_t` exists for a reason.
7. **Pointer casts to parse.** Use `memcpy` and explicit serialisation.
8. **A `switch` that ignores the illegal event.** Log and count it (Level 8).
9. **Forgetting to clear a pending bit.** The ISR re-fires forever.
10. **DMA buffers on the stack.** Static and aligned.
11. **A timeout without wrap handling.** Compare with subtraction, not `>`.
12. **Blocking waits on a bus with no timeout.** A dead device must not hang you.
13. **Flash erase with no thought for ISRs.** The erase halts code running from flash.
14. **A PID without anti-windup.** It saturates and never recovers.
15. **Float in an ISR without thinking about FPU context.** Enable the FPU and understand the stacking.
16. **RDP level 2 on a learning board.** There is no way back.
17. **Measuring consumption with the debugger attached.** You are measuring the debugger.
18. **A binary that only exists on your laptop.** If it did not come from the pipeline, it does not exist.
19. **Copying from CubeMX without understanding what it writes.** Use it to read, not to replace.
20. **A test that passes because it tests nothing.** Break it on purpose to see it fail.

## Appendix D — Out of scope (on purpose)

USB, Ethernet, Bluetooth/Wi-Fi, graphics (LCD/TFT), embedded Linux, functional-safety certification (IEC 61508, ISO 26262 beyond MISRA), advanced DSP beyond Level 20, and full-system security (secure boot with dedicated security hardware). These are good next steps, but they come after this plan, not inside it.
